# 青签 · 产品文档库

本目录是「青签」的产品文档集合,同时作为**站内"使用助手"(智能问答)的知识库**。
文档随代码版本管理;助手按文件与章节检索后作答,回答口径以本文档为准。

## 供检索(RAG)的结构约定

- 每份文档以 `##` 小节组织,**每一节应尽量独立成意**,便于切片后单条命中;
- 面向用户的表述用"你"称呼,功能描述必须与实际产品一致;
- 涉及操作入口时写明准确路径(如"顶部导航 → 求签");
- 功能变更时同步更新本文档(代码与文档同 PR)。

## 站内「使用助手」与知识库

网站右下角的悬浮助手「**青小签**」(形象:笑脸小道童)按本目录文档回答用户的使用问题(接口 `POST /api/assistant/chat`)。

- **参与检索的语料**:`user-guide.md`、`faq.md`、`admin-guide.md`(本索引 README 不参与检索);
- **生效方式**:文档修改后,管理员在「后台管理 → AI 配置 → 重建知识库」重建即可;
- **检索方式**:未配置向量模型时为关键词检索;开通 Embedding 模型(如方舟 `doubao-embedding-text-240715`)并在后台填入后重建,自动升级为 pgvector 向量检索。

# 青签 · 管理后台操作手册

> 面向管理员。登录入口与前台共用,系统按账号自动识别管理员身份。
> 管理员账号配置在服务端 `backend/.env`(`ADMIN_USERNAME` / `ADMIN_PASSWORD`)。

## 进入后台

1. 顶部导航点「登录 / 注册」(与普通用户同一个入口);
2. 输入**管理员账号和密码**,登录后导航栏会出现「管理」入口(也可直接访问 `/#/admin`);
3. 未登录时访问后台会看到引导面板,点击"去登录"即可,登录后自动跳回后台。

> 提示:管理员账号只有配置在服务端的一位;普通用户注册的账号一律是普通身份。

## 概览

进入后台默认看到:抽签总数、今日抽签、AI 解签数、追问消息数、注册用户数,以及 **AI 解签状态卡**(已配置/未配置、当前模型名)。

## 签文记录

- 展示最近全部抽签记录(分页):时间、签文、分类、所问、解签模型、追问数;
- 点击签文可打开对应签文页查看;
- 「删除」:删除该条抽签记录,其关联的解签与追问会**级联删除**(不可恢复);
- 记录含未登录游客的抽签(归属为空)。

## 用户管理

- **搜索**:按用户名 / 昵称模糊搜索;
- **列表字段**:ID、用户名、昵称、注册时间、抽签数、最近抽签时间、状态;
- **重置密码**:点行内「重置密码」→ 输入新密码(≥6 位)→ 保存即生效(用户旧密码立即失效);
- **禁用 / 启用**:禁用后该用户**立即无法登录,已登录会话同步失效**;适合处理异常账号。启用即恢复正常;
- **删除**:删除用户账号,其历史抽签记录会保留(转为匿名记录);
- 普通用户在"签事记"里只能看到**自己**的记录,后台不用于查看用户记录内容。

## 登录日志

- 记录每次**登录与注册**(成功与失败都记录):时间、身份、用户名、事件、结果(失败会显示原因,如"用户名或密码错误""账号已禁用")、IP、设备(浏览器/客户端);
- 「只看失败」:一键筛选异常尝试,用于安全排查(如有人在猜密码);
- 日志分页展示,倒序排列。

## 助手问答

- 记录用户在右下角「使用助手」的每一次问答:时间、提问用户(游客会标注)、问题、回答、检索方式;
- 点击任意行可**展开回答全文与参考来源**;
- **评价统计**:顶部显示"共 X 条 · 👍 Y · 👎 Z · 未评 W";用户可在回答下点赞/点踩;
- 「**只看踩**」:筛选被点踩的问答——**这是优化知识库的入口**:展开看清回答与检索来源,缺什么就补到 `docs/` 对应文档里,再回到「AI 配置 → 重建知识库」使其生效。

## AI 配置

- **接口地址 / 模型 / 温度 / 最大输出 tokens / 思考模式**:按所用大模型服务商填写;OpenAI 兼容接口均可;
- **思考模式**(推理型模型):选择"关闭思考"可让回复更快更稳定,推荐解签场景使用;
- **API Key**:粘贴保存;页面只显示末 4 位;留空表示不修改;可点「清除密钥」停用 AI 解签;
- **保存即生效**,无需重启服务;配置存于数据库,**优先于服务端 .env**;
- **测试连接**:保存后点「测试连接」可验证配置是否可用(返回模型名与延迟);
- 当前默认:火山方舟 deepseek 系列(具体以配置页显示为准)。

## 常见运维问题

### 怎么修改管理员密码?
编辑服务端 `backend/.env` 中的 `ADMIN_PASSWORD`,重启后端服务。修改后旧的管理员登录会自动失效,需重新登录。

### 管理员能看到用户的解签内容吗?
后台的"签文记录"面向运营管理(可删除违规记录)。日常用户记录受"签事记仅本人可见"约束,请遵守隐私边界。

### AI 解签突然不可用了?
检查后台「AI 配置」页的配置状态与「测试连接」结果;若密钥过期或余额不足,需在服务商控制台处理。

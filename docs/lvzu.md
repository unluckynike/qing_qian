# 青签 · 吕祖与吕祖灵签(文化背景)

> 本篇介绍吕祖其人、吕祖灵签的来历与求签的传统讲究,作为文化背景知识。
> 全站内容仅供传统文化娱乐参考,请勿迷信。

## 吕祖是谁

吕祖,即道教八仙中的吕洞宾,原名吕岩,字洞宾,号纯阳子,被道教全真道派奉为"纯阳祖师",故世称吕祖,民间与观音菩萨、关公合称"三大神明"。

相传吕祖成仙之前曾流落风尘,在长安酒馆中偶遇钟离权,一枕黄粱梦醒后感悟世事无常,遂求其超度,经钟离先生点拨、修习方术,得道成仙。他为人乐善好施、扶危济困,深得百姓爱戴;飞升之后,家乡百姓为纪念他修建了"吕公祠"。

在民间,吕洞宾是妇孺皆知、香火极盛的神仙。唐宋以来,他与其余七位神仙并称"八洞神仙"(即八仙),位居八仙之首;《全唐诗》收有吕洞宾诗作二百多首,后世道教与民间称他为剑仙、酒仙、诗仙。时至今日,各地仍多有吕祖祠庙,岁时祭祀,香火不断。

## 信仰简史与吕祖神诞

- 北宋末年,对吕祖的信仰与崇拜开始兴盛。宋徽宗宣和元年(1119 年)封吕祖为"妙通真人";
- 南宋时已有专门奉祀吕祖的庙宇,并有塑像供奉;
- 金代因吕洞宾信奉道教,遂将"祠"改为"观";
- 元世祖至元六年(1269 年)褒赠"纯阳演正警化真君";元武宗至大三年(1310 年)又加封为"纯阳演正警化孚佑帝君";
- 吕祖神诞为**农历四月十四日**,道教信徒多于此日赴道观吕祖殿烧香奉祀,或还愿,或祈愿;
- 华南地区与南洋华人圈盛传吕祖签文,遇有急难,常于吕祖殿神像前求签问卜,祈求神示。

## 吕祖的身世与传说

- **史实说法**:吕洞宾在历史上确有其人,原名吕岩,表字洞宾,号纯阳子。较可靠的说法是——他是唐末五代时的著名道士,与陈抟老祖、杜光庭、谭峭等道家高人同一时期,并有交往。
- **宗室传说**:也有传说称他本是唐朝宗室之后,因武则天欲诛灭李家皇室子孙,不得已随母姓吕。
- **科举与黄粱梦**:吕洞宾自幼聪颖,四书五经、诸子百家过目如流,被称为神童;但生逢唐末,科场腐败,屡试不第。四十六岁时仍赴长安应试,在酒馆中偶遇一位白袍羽士(即八仙中的汉钟离,号"云房先生")在壁上题诗,谈吐不凡,便邀其同住。当夜吕洞宾梦见自己状元及第、官场得意、子孙满堂,继而突因事获罪、家产抄没、妻离子散,只落得孤身一人立于风雪之中。醒来时,汉钟离的一锅小米饭尚未煮熟——此即著名的"黄粱一梦"。吕洞宾由此悟得世事无常、荣华富贵皆是眼前花,遂决心修道,随汉钟离练成一身道法。据说他学成天遁剑法,常仗剑斩妖除害。

## 吕祖灵签是什么

吕祖灵签是吕祖祠庙中用于求签、占卜的签谱,民间用以问卜流年、婚姻、疾病、求财、功名、学业、官司、家宅、运途等,共有一百支,每支签都有其特殊的意义。诚心求签,可在事业、爱情、健康、财运上获得指点。

青签的「签文库」即收录吕祖灵签一百支的完整签文(签诗、解曰、卦象、分项释义),签文是固定的典籍文本,任何情况下不会被改写。

## 传统求签的礼节与讲究

以下为民间传统求签的礼节,供了解;其中部分为线下道观仪轨,线上不必全盘照做:

1. **心诚为先**:抽签须虔诚认真,摒除杂念,不可当玩笑试之;
2. **无事不占**:不随意抽签,遵循"无事不占卜"之说;
3. **净身净手**(传统习俗):古人讲究沐浴更衣,条件不允许时至少洗净双手,以示郑重;
4. **择时辰**(传统习俗):民间认为中午十二点左右、晚上十一点前后(阴阳相接之时)最适宜抽签;
5. **事先确定所问之事**:如婚姻、事业、运程、流年、工作、财运等,一次专注一件事;
6. **默念个人信息**(传统习俗):传统上会默念自己的姓名、出生时辰、年龄、现在居住地址;
7. **一事一签**:每天针对某一件事情进行一次求签为宜,请勿多求。

## 传统做法与线上求签对照

| 传统道观做法 | 青签线上求签 |
|---|---|
| 净身、洗手 | 不必;静心片刻、默念所问之事即可 |
| 择时辰(中午/子时前后) | 随时可求,以心静为准 |
| 默念姓名、出生时辰、住址 | 不要求填写任何个人信息,心中有数即可 |
| 一事一签、每日一事一次 | 相同:建议一事一签,不反复求同一事 |

线上求签保留了最核心的部分——心诚、静心、一事一签;净身、择时等线下仪轨,在网站上简化为"摇签落签"这一仪式。
